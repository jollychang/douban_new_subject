# Security Policy

## Supported version

Security fixes are made for the current Chrome Web Store release. At present, that is `0.1.5`.

## Reporting a vulnerability

GitHub private vulnerability reporting is not enabled for this repository as of 2026-08-13. Please do not disclose a vulnerability in a public issue. Instead, use the developer contact on the [Chrome Web Store listing](https://chromewebstore.google.com/detail/douban-new-subject-helper/akgdaclanljoajifphppdlpkhfgokeih) and include the affected version, impact, reproduction steps, and a minimal proof of concept. Do not include browser cookies, tokens, account credentials, or personal data.

The maintainer should enable GitHub private vulnerability reporting before representing GitHub Security Advisories as a reporting channel. The maintainer will acknowledge a valid report and coordinate a fix before public disclosure.

## Scope

Reports are especially useful for problems involving the content script, host permissions, downloads permission, DOM injection, Presto/Douban parsing, release packaging, or supply-chain integrity.
